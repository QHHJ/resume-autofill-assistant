- 简历专用侧栏、个人信息表格、本地 JSON 文件绑定与写回。
- 使用 Navigator 模型匹配招聘表单字段，不启用 Planner 执行简历填写。
- 支持人工核对后将页面补充信息归入档案。
- 增加简历操作保护、档案路径校验和相关单元测试。
